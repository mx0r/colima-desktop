- **Updates install themselves.** New versions download in the background and install when Colima Desktop quits — or right away with **Restart to Update** in the menu. Switch it off in Settings → Updates.
- **Beta channel.** Settings → Updates → Update channel: **Beta** also offers pre-release versions.
- **Light, dark or System, three times.** Settings sets the appearance of the interface, the terminal and the logs apart, so the terminal can stay dark while the rest follows macOS.
- **Console fonts.** Pick the font, size and line height for the terminal and for the logs. Open windows change at once.
