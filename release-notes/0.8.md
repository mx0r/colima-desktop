- **New Container…** in the menu: search Docker Hub, pick a tag, set the name, command, restart policy, ports, environment variables and volumes in a form, and create the container. A missing image is pulled with progress, and the logs and a terminal are one click away.
- **Image sources** in Settings: Docker Hub for now. Images from other public registries work by name.
- **One copy at a time.** Starting the app again while it runs opens its menu instead of adding a second icon.
